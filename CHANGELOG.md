# Changelog

## 1.3.0

- Own tab in Settings → Discord status instead of Go live → Operate (needs Hostwerk with SDK 3.8) – the status is part of your profile; Discord control (the bot) stays under Go live. / Eigener Reiter unter Einstellungen → Discord-Status statt Livebetrieb → Betrieb (braucht Hostwerk mit SDK 3.8) – der Status gehört zu deinem Profil; die Discord-Steuerung (Bot) bleibt im Livebetrieb.

## 1.2.2

- New animated icon and banner in the common Hostwerk style (isometric block). / Neues animiertes Symbol und Banner im gemeinsamen Hostwerk-Stil (isometrischer Block).

## 1.2.1

- The preview sticks next to the settings while you change them; images per kind, own button and own application are folded into one section / Die Vorschau klebt neben den Einstellungen, während du sie änderst; Bilder je Art, eigener Knopf und eigene Anwendung sind in einen Abschnitt eingeklappt

## 1.2.0

- Lives where it belongs: Go live → Operate → Discord (one tab together with “Discord control”) – no own sidebar entry any more (Hostwerk 3.0+); the full page stays under Extensions → Open and can be pinned in the sidebar settings. / Steckt jetzt dort, wo sie hingehört: Livebetrieb → Betrieb → Discord (ein Reiter zusammen mit „Discord-Steuerung“) – kein eigener Seitenleisten-Eintrag mehr (Hostwerk 3.0+); die ganze Seite bleibt unter Erweiterungen → Öffnen und lässt sich in den Seitenleisten-Einstellungen anheften.

## 1.1.0

- The preview shows the real status that others see – not an example. / Die Vorschau zeigt den echten Status, den andere sehen – kein Beispiel mehr.
- Status dot in the sidebar (connected, off, error) and a place under “System”. / Status-Punkt in der Seitenleiste (verbunden, aus, Fehler) und ein Platz unter „System“.
- No more polling every 5 seconds: the page and the dot update through events; loading and error states with “Try again”. / Keine Abfrage mehr alle 5 Sekunden: Seite und Punkt folgen Ereignissen; Lade- und Fehlerzustand mit „Erneut versuchen“.
- “Use default” button for the application id – an empty field no longer resets silently. / Knopf „Standard verwenden“ für die Anwendungs-ID – ein leeres Feld setzt nicht mehr still zurück.
- Buttons under the status: “View status” (public status page) and one own button. / Knöpfe im Status: „Status ansehen“ (öffentliche Statusseite) und ein eigener Knopf.
- Player count can be switched off; the Minecraft server name is opt-in (with “2/20” party size). / Spielerzahl abschaltbar; Name des Minecraft-Servers als Opt-in (mit Gruppengröße „2/20“).
- Optional image per kind of service (large image of the main kind, small Hostwerk logo). / Auf Wunsch ein Bild je Dienstart (großes Bild der Hauptart, kleines Hostwerk-Logo).
- Design scale instead of fixed sizes; other extensions may add tabs (allowExtensions). / Design-Skala statt fester Größen; andere Erweiterungen dürfen Reiter ergänzen (allowExtensions).
- Release package contains everything except the repository tooling. / Release-Paket enthält alles außer dem Repo-Werkzeug.
- Tests for refusal, reconnecting, privacy of the opt-in fields and the buttons. / Tests für Ablehnung, Neuverbindung, Datenschutz der Opt-in-Felder und die Knöpfe.

## 1.0.1

- Same symbol in the sidebar and in the page header (with Hostwerk 2.11 or newer). / Gleiches Symbol in der Seitenleiste und im Seitenkopf (ab Hostwerk 2.11).

## 1.0.0

- First release as its own extension (before: built into Hostwerk). Data stays where it was. / Erste Fassung als eigene Erweiterung (vorher fest in Hostwerk). Daten bleiben, wo sie waren.
